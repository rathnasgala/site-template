# @rathnasgala/theme

This package contains the versioned, integrity-checked site framework that Gala uses to turn an
author's repository into a fast static publication. Gala installs and updates it automatically; it
is published separately so every generated site can identify the exact framework it runs.

It is not intended as a standalone theme API. To see the complete writing and publishing experience,
visit [gala67.com](https://gala67.com) or create a publication:

```console
npx --yes @rathnasgala/cli@latest init field-notes
```
